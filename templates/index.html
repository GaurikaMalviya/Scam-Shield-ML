    ⊡ METHODOLOGY

    From data to decision.

    01 / Partition by time

    We remove exact repeats and split chronologically into training, validation, and test sets. Transaction time orders the data and is also a model input.

    02 / Choose the alert cutoff

    Training weights counter class imbalance. Validation F1 selects a cutoff for each classifier, then the test set measures performance on later transactions.

    03 / Inspect each prediction

    Tree-path contributions explain CART and Random Forest scores. TreeSHAP explains XGBoost in log-odds. PCA components carry anonymous signals with undisclosed business meanings.
